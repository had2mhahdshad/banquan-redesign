为什么原创作品，更需要提前做好版权保护？

01 参赛学生

别让自己的作品，成为别人的获奖成果。

可能面临的风险
  • 作品被他人盗用、删除署名后冒名参赛。
  • 获奖后遭遇恶意举报，需要投入大量时间解释和举证。
提前登记的价值

办理版权登记，保存设计源文件、草图及创作记录，为原创成果留下权属证明，面对争议时更有据可依。

02 指导老师

学生参赛作品，真的都是自己创作的吗？

可能面临的风险
  • 学生购买设计稿、委托他人代做，却以个人原创作品名义参赛。
  • 作品发生版权或署名争议，指导老师需要配合调查。
提前登记的价值

核对实际创作者、作者署名及素材授权，推动学生赛前完成版权登记，完善作品审核机制。

03 院校

一件作品的争议，可能影响学校声誉。

可能面临的风险
  • 获奖作品被质疑抄袭、冒名或存在版权争议。
  • 赛事宣传撤回、组织核查，甚至引发校园舆情。
提前登记的价值

建立赛前原创核验机制，统一留存作品权属及授权材料，降低事后争议与处置成本。

版权登记，能为参赛作品带来什么？

01

完善参赛材料

为原创作品补充权属证明材料，辅助评审专家了解作品的创作及权属情况。

02

应对恶意举报

遭遇获奖公示质疑或恶意举报时，可提供版权登记证书及创作过程材料，为申诉和争议处理提供支持。

03

辅助侵权维权

作品被抄袭或盗用时，版权登记证书可作为权属证明的初步证据，配合创作记录等材料用于平台投诉及司法维权。

原创保护，越早开始越主动。

版权登记配合创作源文件、版本记录等材料，可以为原创作品提供更充分的权属证明支持。

哪些参赛作品可以登记？

完全适用 可直接登记

视觉与文案类作品

以图片、视频形式提交，去除品牌与赛事元素后即可登记。

  • 平面类、UI 类、视频类、动画类
  • 策划案、文案类、广播类
  • 文案类广告语须 20 字以上

需要把可交互内容转为图片或视频后再登记，不能直接提交网页或工程文件。

  • 互动类（静态 / 动态视觉内容）
  • 科技类（纯文字 / 静态 / 动态 / 图文混合）
  • 营销创客类（微视频、微短剧）
不适用 无法登记

网络直播类

直播过程没有固定载体，无法形成可登记的完整作品文件。

  • 营销创客类（网络直播）
  • 建议改为录制视频后再评估
  • 不确定时先咨询客服

常见问题

作品中出现真人肖像或 AI 生成人物肖像怎么办？
真人肖像需提供所有出镜人的肖像授权，包括作者本人。AI 生成人物肖像请打码处理。
作品中有背景音乐或品牌 IP 特征怎么办？
背景音乐需提供素材授权；建议移除背景音乐。围绕企业品牌 IP 创作的作品，需要去除能够体现该 IP 的内容。
创作协议或授权书的签署时间如何填写？
如作品涉及创作协议或授权书，请确认其签署时间早于作品创作时间。
作品提交版权局后被驳回，可以退款吗？
版权局驳回后可申请退款；因抄袭导致的驳回不予退款。
作品还在版权局审核中，可以申请退款吗？
提交版权局前可申请退款。提交后，需等版权局驳回后再按规则申请；审核通过不适用驳回退款规则。
作品提交截止日期临近，还来得及登记吗？
办理周期为 10–15 个工作日。请按作品提交截止日期预留办理时间；请至少预留完整办理周期，以便安排登记流程。
哪些信息会同步给赛区？
登记信息会同步给赛区，作为原创性参考。具体同步信息按付款前展示的说明确认。
作品提交到版权局后还能修改吗？
提交前请核对作品内容和资料。提交至版权局后，页面资料不可修改。
